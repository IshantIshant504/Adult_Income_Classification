# Adult Income Classification and Clustering

Machine learning project based on an adult-income dataset containing 32,561 records, with 14 input features and one income label.

The project covers exploratory data analysis, data preprocessing, feature engineering, unsupervised clustering and supervised classification.

## Project Workflow

```text
Raw Dataset
    ↓
Exploratory Data Analysis
    ↓
Data Cleaning
    ↓
Feature Engineering
    ↓
Unsupervised Learning
    ↓
Supervised Learning
    ↓
Model Evaluation
```
